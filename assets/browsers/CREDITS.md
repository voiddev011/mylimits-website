# Installation guide image sources

Images are served locally; opening the guide does not contact the source sites.

- `chrome-install.png`: unmodified screenshot captured for this project from the real Google Chrome 156.0.8078.47 extensions page, with Developer mode enabled and no extensions installed. Chrome's official Linux package was verified against the SHA-256 in Google's package metadata before capture.
- `brave-install.png`: unmodified screenshot captured for this project from the real Brave 1.98.60 extensions page, with Developer mode enabled and no extensions installed. The official release ZIP was verified against its published SHA-256 before capture.
- `edge-install.png`: Microsoft, [Sideload an extension](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading), [original image](https://github.com/MicrosoftDocs/edge-developer/blob/main/microsoft-edge/extensions/getting-started/extension-sideloading-images/developermode-toggle.png). Used unchanged. Documentation repository license: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- `firefox-install.png`: Mozilla and individual mozilla.org contributors, [Temporary installation in Firefox](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/), [original image](https://github.com/mozilla/extension-workshop/blob/master/src/assets/img/documentation/develop/about-debugging.png). Used unchanged. See Mozilla's [website content licensing policy](https://www.mozilla.org/foundation/licensing/website-content/).
- `chrome.svg`, `brave.svg`, `edge.svg`, `firefox.svg`: product logos from [alrra/browser-logos](https://github.com/alrra/browser-logos), unchanged. Repository license included in `browser-logos-LICENSE.txt`. Product names and logos remain the trademarks of their respective owners.

Screenshots show settings controls, not an installed MyLimits extension. Example extensions in documentation images belong to the original documentation. Browser layouts may vary across versions and operating systems. These images identify products and explain installation; they do not imply endorsement.
