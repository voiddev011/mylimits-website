Install MyLimits

Choose your browser and follow the steps below.

Get your download first

Use the Chrome ZIP for Chrome, Brave, or Edge. Use the Firefox ZIP for Firefox.

Google Chrome

  1. Unzip the Chrome ZIP.

    Extract the download into a folder you can keep.

  2. Open the extensions page.

    Paste this address into Chrome and press Enter.

    chrome://extensions
  3. Turn on Developer mode.

    Use the switch at the top right.

  4. Click Load unpacked.

    Select the extracted folder containing manifest.json, then confirm. Select the folder, not the ZIP.

  5. Pin and open MyLimits.

    Open the puzzle-piece Extensions menu and pin MyLimits. Click its icon to begin.

Keep the extracted folder. Moving or deleting it can break the extension.

Brave

  1. Unzip the Chrome ZIP.

    Brave uses the Chrome build. Keep the extracted folder.

  2. Open the extensions page.

    Paste this address into Brave and press Enter.

    brave://extensions
  3. Turn on Developer mode.

    Use the switch at the top right.

  4. Click Load unpacked.

    Select the extracted folder containing manifest.json, then confirm.

  5. Pin and open MyLimits.

    Open the puzzle-piece Extensions menu and pin MyLimits. Click its icon to begin.

Microsoft Edge

  1. Unzip the Chrome ZIP.

    Edge uses the Chrome build. Keep the extracted folder.

  2. Open the extensions page.

    Paste this address into Edge and press Enter.

    edge://extensions
  3. Turn on Developer mode.

    Find the switch in the left sidebar.

  4. Click Load unpacked.

    Select the extracted folder containing manifest.json, then confirm.

  5. Show MyLimits in the toolbar.

    Open the puzzle-piece Extensions menu. Show MyLimits in the toolbar, then click its icon.

Firefox

Temporary beta

Reload after restarting Firefox. Temporary add-ons are removed on restart. A permanent install needs a Mozilla-signed release.

  1. Unzip the Firefox ZIP.

    Use the Firefox build, not the Chrome ZIP.

  2. Open the debugging page.

    Paste this address into Firefox and press Enter.

    about:debugging#/runtime/this-firefox
  3. Choose This Firefox.

    The address usually opens this panel directly. If not, select it in the left sidebar.

  4. Click Load Temporary Add-on…

    Open the extracted folder and select the manifest.json file. Here you select the file, not the folder.

  5. Open MyLimits.

    Click the puzzle-piece Extensions button, then MyLimits. Use its menu to pin it to the toolbar.

After installation

Open MyLimits, choose a provider, and approve access to its website. Sign into that provider if prompted. Your overview shows the available usage limits and reset times.

Need help?

“Manifest file is missing or unreadable”

Unzip the download first. In Chrome, Brave, and Edge, choose the folder with manifest.json directly inside it. In Firefox, choose the file itself. Check that you downloaded the right build.

Developer mode is unavailable

Your work or school may block unpacked extensions. Ask your device administrator about the extension policy.

Firefox says the add-on isn’t signed

Use the temporary beta steps above. For a permanent install, use an official store listing or a signed .xpi via about:addons → gear menu → Install Add-on From File…. Leave signature verification enabled.

A reading is missing or out of date

Check that you’re signed into the provider in the same browser profile and have approved MyLimits’ site access. Some providers do not report every limit.
