CHROME / CHROMIUM ZIP

Install in Google Chrome

Developer mode
  1. Extract the ZIP.

    Right-click the downloaded Chrome / Chromium ZIP and choose Extract All (Windows), or double-click it (macOS). Keep the extracted folder somewhere permanent.

  2. Open Chrome’s extensions page.

    Paste this address into Chrome’s address bar and press Enter.

    chrome://extensions
  3. Turn on Developer mode.

    Use the switch at the top right. Additional buttons will appear.

  4. Click Load unpacked.

    Select the extracted folder containing manifest.json, then click Select Folder / Open. Select the folder, not the ZIP or the JSON file.

  5. Pin MyLimits and open it.

    Click Chrome’s puzzle-piece Extensions button in the toolbar, then the pin next to MyLimits. Click MyLimits to get started.

Keep the folder: Chrome loads the extension from that location. Moving or deleting it can break the installation.

SAME ZIP AS CHROME

Install in Brave

Developer mode
  1. Extract the Chrome / Chromium ZIP.

    Brave uses the same extension build as Chrome. Unzip it and keep the extracted folder somewhere permanent.

  2. Open Brave’s extensions page.

    Paste this address into Brave’s address bar and press Enter.

    brave://extensions
  3. Enable Developer mode.

    Turn on the switch at the top right of the extensions page.

  4. Choose Load unpacked.

    Select the extracted folder containing manifest.json. If you see another folder inside the ZIP’s outer folder, open it until you find the manifest.

  5. Pin and open MyLimits.

    Open Brave’s puzzle-piece Extensions menu, pin MyLimits, then click its toolbar icon. You don’t need to turn off Brave Shields to load the extension.

Use the Chrome build: a Firefox extension package will not work in Brave.

SAME ZIP AS CHROME

Install in Microsoft Edge

Developer mode
  1. Extract the Chrome / Chromium ZIP.

    Use the Chrome build for Edge. Unzip the download and keep the extracted folder somewhere permanent.

  2. Open Edge’s extensions page.

    Paste this address into Edge’s address bar and press Enter.

    edge://extensions
  3. Turn on Developer mode.

    Look for the Developer mode switch in the left sidebar. The screenshot shows its location; browser versions may look a little different.

  4. Click Load unpacked.

    Select the extracted folder containing manifest.json and confirm. You do not need to enable “Allow extensions from other stores” for an unpacked install.

  5. Show MyLimits in the toolbar.

    Open the puzzle-piece Extensions menu, choose the show-in-toolbar option next to MyLimits, then click its icon.

On a work or school device? Your administrator may block Developer mode or unpacked extensions. Ask them about your organization’s extension policy.

FIREFOX BUILD ONLY

Install in Firefox

Temporary beta
This beta install lasts until you close Firefox.

Firefox removes temporary add-ons when it restarts. You’ll need to load it again next time. A permanent install requires a Mozilla-signed release or an official store listing.

  1. Extract the Firefox ZIP.

    Download the Firefox build and unzip it. The Chrome / Chromium ZIP is a different build.

  2. Open Firefox’s debugging page.

    Paste this address into Firefox’s address bar and press Enter.

    about:debugging#/runtime/this-firefox
  3. Choose This Firefox.

    The address above usually opens this panel directly. Otherwise, click This Firefox in the left sidebar.

  4. Click Load Temporary Add-on…

    Open the extracted Firefox folder, select the manifest.json file, and click Open. Unlike Chrome, Brave, and Edge, here you select the file itself.

  5. Open MyLimits from Extensions.

    Click Firefox’s puzzle-piece Extensions button, then MyLimits. Depending on your Firefox version, its menu also offers Pin to Toolbar.

Already have a signed Firefox release? Install the signed .xpi using Firefox’s Add-ons Manager (about:addons → gear menu → Install Add-on From File…), or use the official store listing when available. You do not need to disable signature checks.

Your first reading, step by step.

Click the extension icon in your toolbar or find it in your browser’s Extensions menu.

02

Enable the provider you want to track and approve access to its website. Sign into that provider normally if prompted.

Check your overview

See the allowances the provider reports, any available reset times, and the age of the reading. No MyLimits account needed.

Keep the context: ordinary ChatGPT chat quotas are separate from Work / Codex allowance. Missing limits stay unknown. Provider changes, expired sessions, or unavailable plan data can leave readings stale.

A LITTLE HELP, IF YOU NEED IT

Something not looking right?

“Manifest file is missing or unreadable”

Check that you extracted the ZIP first. For Chrome, Brave, and Edge, select the folder with manifest.json directly inside it, rather than a parent folder. In Firefox, select manifest.json itself. Use the build intended for your browser.

I can’t see the MyLimits icon

Check the browser’s Extensions menu (the puzzle-piece icon). Pin MyLimits or choose its show-in-toolbar option. Also check your browser’s extensions page to make sure MyLimits is enabled.

Firefox says the add-on isn’t signed

An unsigned beta cannot be installed permanently through the Add-ons Manager. Use the temporary installation steps above, or wait for a Mozilla-signed release. Leave Firefox’s signature verification enabled.

The extension is installed, but a reading is missing or stale

Open the provider’s website in the same browser profile and check that you’re signed in. Approve any site access MyLimits requests for that provider. Some providers do not expose every limit; MyLimits keeps missing values unknown.

What about independent accounts and the Desktop helper?

Browser tracking uses your existing provider sign-in. Independent Codex and Claude Code profiles use the optional Desktop helper and their official CLI authorization flows. The helper is separate from this browser-extension installation. See the Desktop helper setup and removal guide.
